Libraries & Tools

AnyJev

Lead author and principal maintainer · Nokia Applied Research

Turns any LLM into a typed decision model with calibrated probabilities, training-free by default. A decision endpoint is a vLLM pooling server plus a few kilobytes of closed-form head. Cuts option-order sensitivity 0.230→0.073 and calibration error 0.240→0.095 with zero labels.

SPECTRA

Official implementation · first author

Transform coding for the LLM KV cache. A training-free, drop-in codec that rotates the cache into a coordinate system computed from its own statistics and spends the bit budget on the few channels that carry the signal.

GitHub Paper (arXiv:2608.07915)

WiSP

Official implementation · first author

Routing-aware expert paging for memory-constrained Mixture-of-Experts serving. Treats low-resource MoE inference as a GPU working-set problem, paging in only the experts a workload actually reuses.

GitHub Paper (arXiv:2606.21868)
